# Система подбора участников в команду

Консольное приложение для создания проектных команд, публикации необходимых
ролей и обработки заявок пользователей. В ПР3 функциональная модель проекта из
ПР2 преобразована в объектно-ориентированную.

## Целевая аудитория

- студенты, которые ищут команду для учебных проектов;
- участники хакатонов и соревнований;
- разработчики и специалисты, желающие присоединиться к проектной команде;
- руководители команд, которым нужны участники на конкретные роли.

## Объектная модель

| Класс | Основные атрибуты | Поведение |
| --- | --- | --- |
| `User` | `id`, `name`, `email`, `stack`, `experience` | создание из JSON, преобразование в JSON, строковое представление |
| `Role` | `name`, `stack`, `min_experience`, `vacancies` | проверка соответствия пользователя требованиям роли |
| `Team` | `id`, `name`, `creator`, `description`, `roles`, `members` | добавление роли и участника, поиск роли, проверка свободных мест |
| `TeamMember` | `user`, `role` | связывает объект пользователя с его ролью в команде |
| `Application` | `id`, `team`, `applicant`, `role`, `status` | отмена, принятие или отклонение заявки |

Объекты взаимодействуют напрямую: `Team.creator` хранит объект `User`, а
`Application` содержит ссылки на объекты `Team`, `User` и `Role`. При принятии
заявки в команду добавляется `TeamMember`, который также хранит ссылки на
пользователя и роль.

## Возможности

- регистрация и просмотр пользователей;
- создание команды зарегистрированным пользователем;
- добавление необходимых ролей;
- просмотр, поиск и сортировка команд;
- проверка стека и опыта пользователя перед подачей заявки;
- подача и отмена заявки;
- принятие или отклонение заявки;
- автоматическое добавление принятого пользователя в состав команды;
- подсчёт статистики;
- сохранение объектов в JSON и восстановление связей при загрузке;
- импорт старого формата данных ПР2;
- обработка исключений и некорректного ввода.

## Структура проекта

- `models/` — классы предметной области;
- `users.py` — функции работы с коллекцией пользователей;
- `teams.py` — функции работы с коллекцией команд;
- `applications.py` — функции работы с коллекцией заявок;
- `storage.py` — преобразование объектов в JSON и обратно;
- `main.py` — консольное меню и пользовательские сценарии;
- `utils.py` — безопасный ввод данных;
- `data/users.json` — пользователи;
- `data/teams.json` — команды, роли и состав команд;
- `data/applications.json` — заявки;
- `tests/` — автоматизированные тесты.

## Хранение данных

Во время работы программа использует коллекции `list[User]`, `list[Team]` и
`list[Application]`. В JSON сохраняются только обычные данные. Связи между
объектами представлены идентификаторами:

- команда хранит `creator_id`;
- участник команды хранит `user_id` и название роли;
- заявка хранит `team_id`, `user_id` и название роли.

При загрузке `storage.py` находит соответствующие объекты по идентификаторам и
восстанавливает связи между ними.

## Запуск и проверка

Требуется Python 3.10 или новее.

```bash
pip install -r requirements.txt
python main.py
pytest
flake8
```
