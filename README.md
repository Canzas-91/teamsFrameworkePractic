# Название проекта
Система подбора участников в команду
## Назначение
Система подбора участников в команду позводяющая быстро подобрать подходящих людей в команду для реализации того или иного проекта 
## Целевая аудитория
- студенты, которые ищут команду для учебных проектов;
- участники хакатонов и соревнований;
- разработчики и специалисты, желающие присоединиться к проектной команде;
- руководители и создатели команд, которым необходимо найти участников на определённые роли.
## Предметная область
Предметная область проекта связана с формированием проектных команд и подбором участников.

Пользователь может просматривать существующие команды и доступные в них роли. Если пользователь хочет присоединиться к команде, он может отправить заявку на выбранную роль.

Создатель команды может создавать команду, определять необходимые роли и рассматривать поступившие заявки, принимая или отклоняя кандидатов.
## Основные сущности
- Пользователь
- Команда
- Роль
- Заявка
## Основные функции
- создание и просмотр команд;
- просмотр информации о команде;
- добавление необходимых ролей в команду;
- просмотр доступных ролей;
- подача пользователем заявки на вступление в команду;
- просмотр заявок создателем команды;
- принятие или отклонение заявки;
- добавление пользователя в команду после одобрения заявки.
