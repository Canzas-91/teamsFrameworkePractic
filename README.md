# Система подбора участников в команду

Консольное приложение для создания проектных команд, публикации необходимых
ролей и обработки заявок кандидатов. Проект разработан как индивидуальный
сквозной проект практической работы № 2.

## Целевая аудитория

- студенты, которые ищут команду для учебных проектов;
- участники хакатонов и соревнований;
- разработчики и специалисты, желающие присоединиться к проектной команде;
- руководители и создатели команд, которым нужны участники на конкретные роли.

## Возможности

- создание команды и добавление необходимых ролей;
- просмотр, поиск и сортировка команд;
- просмотр свободных ролей;
- проверка соответствия стека и опыта кандидата требованиям роли;
- подача и отмена заявки;
- принятие или отклонение заявки создателем команды;
- автоматическое добавление принятого кандидата в состав команды;
- подсчёт статистики по командам, ролям, участникам и заявкам;
- сохранение и загрузка данных в формате JSON;
- обработка некорректного ввода и ошибок предметной области.

## Основные сущности

- **Команда** — название, создатель, описание, роли и участники;
- **Заявка** — кандидат, команда, роль, опыт и статус рассмотрения;

## Структура проекта

- `main.py` — точка запуска, меню и сценарии взаимодействия;
- `teams.py` — команды, роли, поиск, сортировка и статистика;
- `applications.py` — подача, отмена и рассмотрение заявок;
- `storage.py` — загрузка и сохранение JSON-файлов;
- `utils.py` — безопасный ввод данных;
- `data/teams.json` — команды, роли и участники;
- `data/applications.json` — заявки кандидатов;
- `tests/` — автоматизированные тесты pytest;
- `requirements.txt` — инструменты тестирования и проверки кода.

## Формат данных

Данные хранятся в JSON как списки словарей. Команда содержит вложенные списки
ролей и участников. Заявка ссылается на команду через `team_id` и имеет один из
статусов: `pending`, `accepted`, `rejected` или `cancelled`.

## Требования

- Python 3.10 или новее;
- pytest;
- flake8.

Установка инструментов разработки:

```bash
pip install -r requirements.txt
```

## Запуск программы

```bash
python main.py
```

## Запуск тестов

```bash
pytest
```

## Проверка качества кода

```bash
flake8
```

Классы предметной области пока не используются: данные представлены словарями
и списками, а поведение — функциями. Объектную модель можно добавить на этапе ПР3.
